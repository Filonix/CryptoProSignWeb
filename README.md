# CryptoProSignWeb

Веб-приложение для массового подписания и проверки файлов с использованием КриптоПро ЭЦП Browser Plug-in (CAdES).

## 📋 О проекте

**CryptoProSignWeb** — это одностраничное веб-приложение (SPA), которое позволяет:
- Подписывать файлы электронной подписью с помощью сертификата, установленного в системе КриптоПро.
- Проверять подписи файлов (как присоединённые, так и отсоединённые).
- Добавлять штамп времени на PDF-документы при подписании.
- Работать с несколькими файлами одновременно (массовое подписание/проверка).

Приложение использует КриптоПро ЭЦП Browser Plug-in для работы с сертификатами и создания электронной подписи в браузере.

## 🚀 Функциональность

### Подписание файлов
- Загрузка одного или нескольких файлов для подписания.
- Выбор сертификата из списка доступных в системе.
- Выбор типа подписи:
  - **Присоединённая** — подпись и файл сохраняются в одном файле.
  - **Отсоединённая** — подпись сохраняется в отдельном файле.
- Добавление штампа времени на PDF-файлы (опционально).
- Отображение прогресса подписания.
- Возможность скачать все подписанные файлы одной кнопкой.

### Проверка подписей
- Загрузка файлов для проверки подписи.
- Для отсоединённых подписей — загрузка соответствующих файлов подписей.
- Проверка корректности электронной подписи.

## 🛠️ Технологии

- **HTML5 / CSS3** — интерфейс приложения.
- **JavaScript (ES6+)** — логика работы с плагином и файлами.
- **КриптоПро ЭЦП Browser Plug-in** — работа с сертификатами и создание подписи.
- **JSZip** — упаковка нескольких файлов в ZIP-архив для скачивания.
- **pdf-lib** — работа с PDF-документами (добавление штампа времени).

## ⚙️ Установка и запуск

### Требования
1. Установленный **КриптоПро ЭЦП Browser Plug-in**:
   - Скачать с [официального сайта КриптоПро](https://www.cryptopro.ru/products/cades/plugin)
2. Поддерживаемые браузеры: Google Chrome, Mozilla Firefox, Opera, Yandex Browser и другие на основе Chromium.
3. Установленный **КриптоПро CSP** (криптопровайдер) с действующим сертификатом в хранилище.

### Запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Filonix/CryptoProSignWeb.git
   ```
2. Откройте файл `index.html` в браузере с установленным плагином КриптоПро.

> ⚠️ **Важно:** Для корректной работы плагина страница должна быть открыта по протоколу `https://` или `http://localhost`. Некоторые браузеры блокируют работу плагина при открытии через `file://`.

## 🖥️ Использование

### Подписание файлов
1. На вкладке «Подписать файлы» нажмите «Выберите файлы для подписи» и выберите один или несколько файлов.
2. Дождитесь загрузки списка сертификатов и выберите нужный.
3. Выберите тип подписи:
   - **Присоединённая** — результат будет содержать файл с встроенной подписью.
   - **Отсоединённая** — подпись будет сохранена в отдельном файле (с расширением `.sig`).
4. При необходимости включите опцию «Добавить штамп на PDF».
5. Нажмите «Подписать файлы».
6. После завершения подписания нажмите «Скачать все подписи», чтобы получить архив с результатами.

### Проверка подписей
1. Перейдите на вкладку «Проверить подписи».
2. Выберите файлы для проверки.
3. Если проверяются отсоединённые подписи, загрузите соответствующие файлы подписей.
4. Нажмите «Проверить подписи».
5. Результат проверки отобразится на экране.

## 🔧 Настройка

Приложение не требует дополнительной настройки. Все параметры (тип подписи, штамп времени и т. д.) выбираются через интерфейс.
